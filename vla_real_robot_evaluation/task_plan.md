## 关键问题

1. 既有 VLA 工作真机评测通常如何选任务、划分 ID/OOD、设置重复次数和判定成功？
2. 除成功率外，效率、轨迹质量、泛化、鲁棒性、安全、人机介入和系统性能如何测量？
3. 如何通过随机化、盲评、置信区间和失败分类，避免小样本真机实验产生误导？
4. 一个可复用评测系统应记录哪些元数据、事件、视频、动作和版本信息？
5. Genie02 现有 GSR/TTS/平滑度能力可直接复用什么，还缺什么？

## 决策

| 决策 | 理由 |
|---|---|
| 以桌面固定机械臂操作为核心，兼容双臂和移动操作 | 与现有 Genie02 抓取数据衔接，同时保持 VLA 框架通用性 |
| 分为“惯例证据、测量科学、系统落地”三条并行调研线 | 相互独立，适合子 agent 并行填充且便于最终交叉核验 |
| 所有下载和解析中间物放在 `tmp/agent-*` | 满足临时文件隔离要求，避免污染最终交付目录 |
| 成功率必须配置信区间、分层结果和试验清单 | 真机样本通常较小，仅报点估计容易产生错误结论 |
