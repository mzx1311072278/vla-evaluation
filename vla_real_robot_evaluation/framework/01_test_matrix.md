# VLA 真机分层测试矩阵

> 版本日期：2026-08-04。下述试验数与阈值是面向工程验收的建议，不是论文共识。论文常见每任务 5--20 次，RT-1/RT-2 也有数千 rollout 的大规模内部评测；证据综述见 [既有惯例](../research/01_real_world_precedents.md)。项目必须按风险、目标成功率和可接受置信区间调整样本量。

## 1. 统一测试单元和记录口径

### 1.1 测试单元

一个最小测试单元定义为：

`policy checkpoint x robot/config x task x condition x initial-state ID x instruction ID x repeat`

每条 rollout 至少记录：模型/代码 commit、权重 checksum、机器人序列号、控制频率、相机标定、任务/条件/初态 ID、随机种子、开始结束时间、完整成功、各子步骤、超时、失败类型、人工介入、急停/碰撞、基础设施异常、视频和传感器日志。

### 1.2 成功和分母

- **完整成功率（Full SR）**：`无人工帮助且在时限内满足全部预注册终态 / 所有有效启动 rollout`。这是主指标。
- **任务进度（Progress）**：完成的预注册子步骤权重之和 / 满分。只作诊断，不替代 Full SR。
- **恢复状态率**：扰动成功施加且扰动前未失败的 eligible trials 中，在冻结恢复窗内重新达到“可继续任务”状态的比例。
- **扰动层 Full SR（canonical gate）**：最终严格成功 / 所有分配到该扰动 stratum 的 valid trials。保持 planned-stratum/ITT-style 分母，不因扰动未成功施加或策略提前失败而改用更有利的 eligible 子集。
- **语言选对率**：第一次接触/抓取的目标是否与指令一致；多物体场景须与动作成功率分报。
- **安全事件率**：碰撞、越界、超力、掉落危险物、急停次数 / rollout。严重安全事件不能被平均成功率抵消。
- **基础设施取消**：相机掉线、控制器故障、非策略原因的硬件保护。只允许按预注册规则剔除，并同时报告原始分母、剔除数和原因。策略诱发的急停、卡死、超时计失败。

二项指标报告 `successes / n`、点估计和 95% Wilson 区间；连续分数报告均值、中位数、标准差/四分位距和 bootstrap 95% 区间。不得只报告跨任务宏平均；同时给逐任务结果和按任务等权宏平均。

### 1.3 公平性控制

- 使用冻结的 task manifest、初态清单、对象集合、指令清单、时限和 rubric。
- 多策略比较采用配对初态，并以 ABBA/随机区组交错执行，避免照明、温度、电量和操作员学习效应。
- 每条策略使用相同控制频率、相机输入、动作空间、低层控制器和安全限制；若无法相同，列为独立 system-level 比较。
- 零样本、少样本、充分微调分开建表；记录 target robot/task 数据量、训练 step、算力和选 checkpoint 方法。
- 测试对象、背景和指令不得在 checkpoint selection 中使用。仿真回归可以筛 checkpoint，但真机测试集只运行冻结候选。

## 2. 分层矩阵

| 层级 | 测试单元 | 变量控制 | 建议试验数 | 工程通过条件 |
|---|---|---|---|---|
| L0 冒烟 | 3--5 个已见基础技能：到达、抓取、放置、开/关或平台核心动作 | 固定对象、固定背景；初态仅 2--3 个标称位置；先低速/软物体 | 每任务 3--5 次；每次更新权重/控制栈后重跑 | 无严重安全事件/越界/失控；推理与控制频率达到配置；至少 90% rollout 启动并产生合理动作；若作为功能 gate，建议 5/5 完整成功后进入 L1 |
| L1 ID 基线 | 业务核心原子任务；每个动词-对象族至少 2--3 个任务 | 与训练分布一致；位置按冻结列表随机；同初态配对基线 | 开发筛选 10/任务；候选筛选 20--30/任务；正式门禁按 SLO/margin/power 反算 | 每任务 Full SR 的预注册置信下界达到任务 SLO；无不可接受严重事件/保护失效；相对基线满足预注册非劣 margin；样本预算不足则 `INCONCLUSIVE` |
| L2a 空间泛化 | 相同任务，改变目标/容器 xyz、yaw、距离、机器人底座偏差 | 只改空间变量；对象、光照、背景、指令不变；位置分桶 | 每任务每难度 20；边界位置建议 30 | 各桶 Full SR 达到 SLO；OOD/ID 保持率建议 >=0.80；不得存在连续不可达盲区；位置误差与失败热图完整 |
| L2b 物体泛化 | seen instance、同类新 instance、新类别/新材质/尺寸/透明/易变形 | 固定位置和背景；按物理属性配对；夹爪条件不临时调整 | 每任务每对象组 20；高风险物体 30 | 同类新 instance 保持率建议 >=0.80；新类别阈值由业务设定；错误目标接触率低于预注册上限；不可接受危险掉落为 0 |
| L2c 背景/场景泛化 | 桌布/台面、光照、相机小偏差、干扰物、遮挡、新房间 | 单变量阶梯：纹理 -> 光照 -> 干扰物 -> 遮挡 -> 新场景；对象/任务固定 | 每任务每级 20；新场景至少 3 个地点 x 10 | 每一级报告保持率和置信区间；建议单变量保持率 >=0.80，新地点宏平均 >=0.70；不可接受严重事件和保护失效为 0，其他事件按 profile 门禁 |
| L2d 指令泛化 | 同义改写、属性指代、关系、否定/约束、多语言、互联网概念 | 相同初态含 K 个候选对象；提示顺序随机；禁止操作者追加解释 | 每模板/对象组合 10；每大类至少 30 | language selection 显著高于 1/K chance；建议选对率 >=0.90、完整任务 >= ID 的 0.80；解析失败与运动失败分报 |
| L2e 组合泛化 | 两到三轴同时变化：新对象+新位置、背景+干扰、指令+对象+场景 | 使用正交/分数因子设计；保留对应单轴条件用于归因 | 每组合 cell 20；关键组合 30 | Full SR 达业务 SLO；相对最差单轴的额外组合损失建议 <=15 pp；无只靠场景捷径的证据 |
| L3 扰动恢复 | 执行中移动目标/容器、抓取滑脱、轻度遮挡、增加干扰物、底座偏移、一次动作受阻 | 扰动时间和幅度预注册；设无扰动 paired control；安全员只负责急停 | 每任务每扰动级 20；包含早/中/晚阶段 | canonical 扰动层 Full SR 使用全部 valid 分配 trial；恢复状态率/时间使用冻结 eligible 子集；人工接管=失败；不可接受严重事件和保护失效为 0 |
| L4 长程任务 | 3--5、6--10、10+ 原子步骤；导航+操作；可变形/关节物体；业务完整流程 | 固定高层命令；自动 HL 与 human-oracle 分栏；每步骤 rubric 和总时限预注册 | 低成本 10/任务；发布筛选 20；正式门禁按 SLO/power 反算 | 同时报 Full SR、Progress、关键步骤 SR、接管率、时长；关键流程 Full SR 下界达 SLO；不得用高 progress 掩盖 0 次完整成功 |
| L5 跨机器人（可选） | 同语义任务在已见与新 embodiment；zero-shot 与 target-data adaptation | 对齐观察/动作定义和安全栈；分别固定 0/10/50/100 demos 或小时预算 | 每机器人每任务每数据档 20；至少 5 个共享任务 | 仅在 0 target data 时称 zero-shot；adaptation 与同数据 scratch/专用策略比较；保持率、数据效率、控制频率和安全均达预注册目标 |

表内固定次数均是筛选或排期起点，不自动满足正式门禁。正式发版必须在执行前依据目标 SLO、置信界、非劣 margin、基线成功率、配对 discordance 和目标 power 反算每个 mandatory stratum 的样本量；预算不足或区间跨越门限时判 `INCONCLUSIVE`。

## 3. 各层执行细则

### 3.1 L0 冒烟

目的不是估计真实性能，而是阻止错误 checkpoint、动作归一化、坐标系、相机顺序和夹爪语义进入正式评测。

建议顺序：空载关节/末端限位检查 -> 软物体 reach -> grasp -> place -> 平台特有动作。任何坐标反向、持续饱和、控制延迟超过预算、夹爪反相或安全边界触发，立即停止并回到离线回放/仿真。L0 结果不能作为对外成功率。

### 3.2 L1 ID

ID 不等于“初态完全固定”。沿用 RT-1/OpenVLA 的做法，即任务、对象族和场景在训练支持域内，但物体位置、机器人初姿、时段和轻微传感噪声仍按冻结清单变化。每个任务先写机器可检查的终态；做不到时使用双人盲标或视频复核，并报告一致率。

建议至少有一个专用策略/现网策略作为 system baseline；另设“最后动作不执行”或随机/常量策略仅用于验证 rubric 不会误判。

### 3.3 L2 单轴与组合泛化

推荐 manifest 结构：

| 轴 | ID | OOD-1 | OOD-2 | 必须保持不变 |
|---|---|---|---|---|
| 空间 | 训练中心区域 | 边缘/远距离/新 yaw | 高度变化/底座偏差 | 对象 instance、背景、指令 |
| 物体 | 训练 instance | 同类别新 instance | 新类别/新材质或尺度 | 位置桶、背景、句式 |
| 背景 | 原台面/光照 | 新纹理/光照 | 新房间+相机小偏差 | 对象、位置桶、指令 |
| 指令 | 标准模板 | 同义改写/属性 | 关系、组合、多语言 | 初态、候选物体、动作目标 |

组合测试至少包括 ID、每个单轴 OOD 和组合 OOD。若只测组合条件，失败后无法判断视觉、语义还是控制问题。OpenVLA 的视觉/运动/物理/语义分栏和 RT-1 的 L1/L2/L3 叠加难度可直接作为设计参考，证据见[调研 §2.1、§2.5](../research/01_real_world_precedents.md)。

### 3.4 L3 扰动恢复

每种扰动定义幅度、触发时刻、持续时间和安全边界，例如：

- approach 阶段将目标平移 5 cm / 10 cm；
- grasp 后允许一次自然滑脱，不人工扶正；
- 放置前移动容器 5 cm；
- 短时遮挡主相机 0.5 s / 1 s；
- 场景中加入 3 / 8 个无关干扰物；
- 低层控制器拒绝一次不安全动作，观察策略是否重新规划。

必须保留原始失败动作，而不是只展示成功 recovery 视频。记录首次恢复动作延迟、重试次数、是否回到可达状态和最终完整成功。策略造成的碰撞/急停不可当作“实验中断”剔除。

### 3.5 L4 长程

长程采用两套指标：

1. **严格终态**：全部步骤完成才记 1，其他为 0。
2. **诊断 rubric**：每个不可逆里程碑计分，并标记失败发生在哪一步。

高层控制条件必须明确：flat high-level prompt、模型自主 HL、外部 planner、human oracle。参考 pi0/pi0.5，human oracle 只用于估计低层能力上限，不能进入 autonomous 主结果；参考 RT-1，同时报告 planning success 和 physical execution success，证据见[调研 §2.1、§2.6--2.7](../research/01_real_world_precedents.md)。

### 3.6 L5 跨机器人

至少拆成三类声明：

- **zero-shot embodiment**：目标机器人没有训练/微调/校准轨迹，只有动作接口映射；
- **few-shot adaptation**：固定 10/50/100 demos 或 0.5/1/5 小时；
- **full adaptation**：按收敛预算训练。

对比 target-data scratch、通用预训练+微调、专用策略；所有方法使用同一 target data 和 checkpoint selection 规则。Octo/RDT/SmolVLA 表明论文中的“未见对象/机器人”常混有目标机器人微调，报告必须写清 target-data 边界，证据见[调研 §2.4、§3.1、§3.3](../research/01_real_world_precedents.md)。

## 4. 推荐统计门槛

以下是默认工程起点，不是普适质量标准：

| 用途 | 最小建议 | 原因与限制 |
|---|---|---|
| 日常回归 | 5--10/任务 | 能发现大退化，不能证明高可靠 |
| 模型候选比较 | 20/任务/条件，配对初态 | 可做 paired bootstrap/McNemar；对小差异仍可能无力 |
| 发布预算起点 | 30--50/关键任务/条件 | 仅用于排期；正式 n 必须按 SLO、非劣 margin、基线率、配对 discordance 和 power 反算，预算不足判 `INCONCLUSIVE` |
| 高风险/高可靠任务 | 100+ 或序贯检验 | 目标若是 95%/99% 可靠，少量试验无法建立置信度 |
| 5--20 分钟长程 | 10 开发、20 发布 | 成本高；必须辅以逐步指标，但不能放弃 full success |

默认比较优先级：不可接受严重安全事件和保护失效（必须为 0） -> Full SR 下界 -> 接管率 -> OOD/ID 保持率 -> Progress -> 时长/吞吐。允许的 warning、正确 safe-stop 等事件仍需按 safety profile 分层报告。不得通过调整部分得分权重逆转完整成功结论。

## 5. 发布报告最小表格

每次正式评测至少发布以下逐任务表：

| Policy | Robot | Task | Condition | Target-data budget | Success / n | Full SR (95% CI) | Progress | Takeover rate | Safety events by severity | Infra cancels | Median time | Failure top-3 |
|---|---|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---|

同时附：

- 冻结 manifest 和 rubric 版本；
- 初态配对与执行顺序；
- 所有取消/接管/急停明细；
- 逐 rollout 机器可读记录与视频索引；
- 仿真与真机结果分开的表；
- zero-shot/few-shot/full-adaptation 的明确标签；
- 与基线不一致的输入、动作、控制频率、训练数据和 checkpoint 选择差异。

## 6. 建议的首轮最小可执行组合

预算受限时，首轮建议 8 个任务：3 个基础 pick/place、1 个关节物体、1 个精细操作、1 个语言 grounding、1 个扰动恢复、1 个 5+ 步长程。先做 L0 每任务 3 次；通过后做 L1/L2/L3 每个关键 cell 20 次，长程 10 次。约束如下：

- 每个 OOD cell 只改一个变量，另设 2 个组合 cell；
- 所有模型使用相同 20 个初态并交错执行；
- 预注册 full success、partial rubric、时限和安全停止；
- 第一轮只用于筛模型；30--50 次/关键任务仅作正式评测预算起点，最终样本量按冻结 SLO、margin 与 power 反算，不足则 `INCONCLUSIVE`。

该组合继承了 RT-2/OpenVLA 的配对 A/B、RT-1 的单轴到组合难度、pi0/pi0.5 的长程 rubric 和 DROID 的 ID/OOD 同任务设计，同时补齐论文普遍缺失的接管、安全、取消和统计分母。
